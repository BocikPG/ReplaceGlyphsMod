# Replace Glyph Mod

It's a mod for `Chants of Sennaar` that will allow to replace in-game glyph with your own, or random ones using my [GlyphGenerator](https://github.com/BocikPG/GlyphGenerator).

## AI disclosure

I don't use AI for coding this mod. No original game code was send to LLM's.

I use AI to browse the web but never copy it's suggestions, sometime using Copilot for repetitive tasks (like creating 5 similar fields).
